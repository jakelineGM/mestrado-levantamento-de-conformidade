# Ordenação de notas com Pigeonhole Sort

Ordenação de notas com Pigeonhole Sort
Escreva um programa que lê uma lista de notas de um processo seletivo e imprime o ranking dos candidatos.
Os candidatos deverão ser ordenados por notas usando o algoritmo de ordenação Pigeonhole Sort.
Como o Pigeonhole Sort só ordena chaves inteiras e as notas possuem uma casa decimal, você deverá converter as notas do intervalo [0,10] para o intrvalo [0,100] multiplicando as notas por 10 antes de ordenar.
