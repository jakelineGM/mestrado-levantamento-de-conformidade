# Comparações do Bubble Sort

Comparações do Bubble Sort
Implemente uma função chamada imprime_bubble que testa a versão do Bubble Sort que possui complexidade temporal O(n) no melhor caso—ou seja, a versão que utiliza uma flag para interromper o algoritmo quando o vetor já estiver ordenado.
Para testar o tempo de execução, dentro da função você imprimir uma string no formato {} > {}? a cada comparação de elementos realizadas pelo Bubble Sort. As sequências de chaves devem ser substituídas pelos dois valores comparados, sendo que o primeiro par de chaves deve corresponder ao elemento com menor índice.
Escreva um programa principal que lê uma lista de valores que poderão ser inteiros, strings etc. Chame a função e deixe que ela imprima as trocas realizadas. Ao final, imprima a lista resultante.
