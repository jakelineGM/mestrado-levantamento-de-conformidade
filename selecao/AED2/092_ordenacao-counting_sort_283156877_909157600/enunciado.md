# Espaço de trabalho do Counting Sort

Espaço de Trabalho do Counting Sort
Elabore um programa que contém uma implementação do algoritmo de ordenação linear Counting Sort que retorna:
A lista que representa o espaço de trabalho do Counting Sort
A entrada ordenada
O espaço de trabalho do Counting Sort é uma lista de inteiros (m0​,m1​,m2​,…,mk−1​) no qual k=max(L)−min(L)+1 representa o tamanho do intervalo entre a maior e a menor chaves da lista de entrada L e cada elemento mi​ é a contagem da i-ésima chave.
Imprima primeiro o espaço de trabalho, depois a saída ordenada.
