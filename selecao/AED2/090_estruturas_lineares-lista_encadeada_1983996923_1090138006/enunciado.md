# Inserção na lista encadeada

Inserção na lista encadeada
Complete as funções lst_cria e lst_insere_inicio:
lst_cria(): cria uma nova lista encadeada vazia
lst_insere_inicio(lis, elem): cria um novo nó com o valor do elemento passado por parâmetro e o insere no início da lista encadeada.
Veja que já existe uma função chamada lst_imprime que percorre toda a lista encadeada e imprime seu conteúdo.
O programa principal deverá ler um único número inteiro N e inserir os valores 1, 2, 3, ..., N na lista encadeada. Como os valores devem ser inseridos no início, a impressão produzirá uma sequência em ordem decrescente.
