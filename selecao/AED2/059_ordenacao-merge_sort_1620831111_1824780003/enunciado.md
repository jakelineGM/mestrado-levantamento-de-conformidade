# Mesclagem de vetores (E/S Python)

Intercalação de listas (E/S para Python)
Escreva uma função que recebe como entrada duas listas completamente ordenadas e retorna uma lista a intercalação dos vetores originais. Por exemplo, se as listas forem A e B com os elementos a seguir:
A=[1,3,3,5,7]
B=[2,4,5,5,6]
Então a saída deverá ser
C=[1,2,3,3,4,5,5,5,6,7]
Depois faça um programa que lê duas listas em notação Python e imprime a lista resultante da intercalação das duas listas.
