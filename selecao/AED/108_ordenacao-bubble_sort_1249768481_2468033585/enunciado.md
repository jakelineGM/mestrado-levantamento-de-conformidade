# Trocas do Bubble Sort

Trocas do Bubble Sort
Elabore uma função chamada imprime_bubble(v). Nela, você deverá implementar o algoritmo de ordenação Bubble Sort (método da bolha), mas com uma modificação: sempre que você trocar dois elementos de lugar, você deverá imprimir a troca que foi realizada com a notação {} <-> {}, sendo que o primeiro par de colchetes deve ser substituído pelo elemento à esquerda na troca e o segundo pelo elemento da direita.
Escreva um programa principal que lê uma lista de valores que poderão ser inteiros, strings etc. Ordene e deixe a função imprimir as trocas realizadas. Ao final, imprima a lista ordenada.
Obs.: a lista dever ser ordenada de maneira crescente.
