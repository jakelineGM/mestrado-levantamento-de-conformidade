# Tamanho da Lista

Implemente uma função que tenha como valor de retorno o comprimento de uma lista encadeada, isto é, que calcule o número de nós de uma lista. Essa função deve obedecer o protótipo:
int comprimento(Lista* l);
Entrada
A entrada é composta por um número N de elementos positivos que compõem a lista.
Saída
Como saída imprima o retorno da função comprimento.

## Dicas

Não altere a main
