# Consultas ao dicionário

Lista de termos
Escreva um programa que lê um dicionário de palavras com cinco letras (neste contexto, dicionário é apenas uma lista de palavras).
Em seguida, leia uma série de consultas e verifique se as palavras consultadas estão presentes no dicionário ou não.

Entrada
A entrada começará com um inteiro N dizendo o tamanho do dicionário e depois seguir-se-ão N palavras de cinco letras.
Depois haverá um inteiro M dizendo o número de consultas e seguir-se-ão M palavras de cinco letras.
As palavras do dicionário serão todas em caracteres maiúsculos, mas as palavras de consulta poderão ter qualquer caixa.

Saída
Para cada palavra consultada, verifique se ela está presente no dicionário ou não.
Caso esteja, imprima a string %s ok.
Caso não esteja, imprima a string %s nao existe.
