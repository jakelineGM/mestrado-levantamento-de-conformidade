# Inserir elementos do vetor em uma Pilha

Faça uma função que receba como parâmetro uma pilha vazia e um vetor de inteiros contendo K posições. A função deve inserir na pilha cada valor encontrado no vetor. A ordem de inserção deve ser do primeiro para o último elemento do vetor. Os dados da pilha neste caso são do tipo int.

## Dicas

Obs: utilize as implementações das operações da pilha feita nas outras quesões. Não esqueça de moficar o tipo de dado para int
