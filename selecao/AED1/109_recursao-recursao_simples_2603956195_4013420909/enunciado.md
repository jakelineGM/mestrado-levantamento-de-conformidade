# Conversão de decimal para binário com recursão

Escreva uma função recursiva chamada imprime_bin(num) que recebe como entrada um número positivo menor que 231 e imprime a representação binária desse número.
Utilize operações de divisões por 2 e restos para encontrar a representação binária. Use a função printf para imprimir o próximo bit de cada chamada recursiva.
