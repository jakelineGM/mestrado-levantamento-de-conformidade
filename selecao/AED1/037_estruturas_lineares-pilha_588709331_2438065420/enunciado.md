# Pilhas com lista

Implemente um programa que simule as operações de uma pilha de acordo com a seguinte lógica:
Se o usuário digitar -1, a entrada se encerra, e a pilha remanescente deve ser impressa:
Se a pilha estiver vazia, imprima "pilha vazia!".
Caso contrário, imprima os elementos da pilha do topo até a base.

Se o usuário digitar 0, remova o elemento do topo da pilha:
Se a pilha estiver vazia, imprima "pilha vazia!".

Se o usuário digitar 1, o próximo número fornecido pelo usuário deve ser inserido no topo da pilha.

## Dicas

Implemente pilhas utilizando listas encadeadas como fornecido nos slides da aula.
