# Concatena listas

Implemente uma função que receba duas listas encadeadas de valores reais e transfira para o final da primeira lista os elementos da segunda. No final, a primeira lista representará a concatenação das duas listas e a segunda lista estará vazia. Essa função deve obedecer ao protótipo:
Lista *concatena(Lista* l1, Lista* l2);
Entrada
A primeira linha é composta por um inteiros N, que representa os número de elementos da primeira lista. A segunda linha é composta por N inteiros que representam os elementos presentes na lista.
A terceira linha é composta por um inteiros T, que representa os número de elementos da segunda lista. A quarta linha é composta por T inteiros que representam os elementos presentes na lista.
Saída
Como saída imprima a primeira lista depois de executar a função concatena.
