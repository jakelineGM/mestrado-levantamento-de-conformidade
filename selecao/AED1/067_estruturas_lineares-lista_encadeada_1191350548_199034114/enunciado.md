# Removendo Segundo Elemento de uma Lista Circular

Considere uma lista encadeada do tipoLista onde o último elemento aponta para o primeiro elemento, sendo, portanto, uma lista circular. Faça uma função para remover o segundo elemento da lista, garantindo que ela permanecerá sendo uma lista circular após a remoção. Considere que a lista passada para a função contém elementos. 
Considere que o segundo elemento é o que vem após o apontado pelo campo prim do tipoLista.
