# Única Ocorrência

Implemente uma função que receba um vetor ordenado de inteiros e uma chave, também inteira. A função deve retornar verdadeiro (SIM) caso a chave ocorra exatamente 1 vez no vetor, retornando falso (NÃO) em caso contrário. Considere que o vetor pode conter repetições de valores. Utilize busca binária para implementar a solução para o problema fornecido.
