# Função para busca sequencial

Busca sequencial
Escreva uma função que realiza busca sequencial por uma chave em um vetor de valores inteiros. Se a chave estiver presente no vetor, a função deverá retornar o índice da primeira ocorrência. Se a chave não aparecer no vetor, a função deverá retornar o valor -1.
Elabore também um programa que lê um vetor de N elementos inteiros (o valor de Ndeverá ser informado antes do conteúdo do vetor), seguido de uma série de chaves. Para cada chave, seu programa deverá informar a posição da chave no vetor ou imprimir uma mensagem dizendo que a chave não foi encontrada. Pare quando um valor não numérico for digitado no lugar de uma chave.

## Dicas

Para saber se o usuário digitou um valor inteiro (correspondente a uma chave) ou um valor não numérico, teste o retorno da função scanf. Se o retorno da função for diferente de 1, então quer dizer que o usuário não digitou um número e nenhuma conversão foi realizada.
