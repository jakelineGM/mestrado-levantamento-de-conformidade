# Merge de listas

Implemente uma função que construa um nova lista, intercalando os nós de outras duas listas passadas como parâmetros. Essa função deve retornar a nova lista resultante, criada dentro da função.
Ao final da função, as listas originais devem ficar vazias e ser liberadas. Se uma lista tiver mais elementos que a outra, os elementos são transferidos na mesma ordem para a nova lista. Essa função deve seguir o protótipo:
Lista* merge(Lista* l1, Lista* l2);
Entrada
A primeira linha é composta por um inteiros N, que representa os número de elementos da primeira lista. A segunda linha é composta por N números reais que representam os elementos presentes na lista.
A terceira linha é composta por um inteiros T, que representa os número de elementos da segunda lista. A quarta linha é composta por T números reais que representam os elementos presentes na lista.
Saída
Como saída imprima a lista resultante da função merge.
