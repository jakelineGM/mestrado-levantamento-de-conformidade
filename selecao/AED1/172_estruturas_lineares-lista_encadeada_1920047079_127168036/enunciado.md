# Último da lista

Implemente uma função que retorne o último valor de uma lista encadeada de inteiros. Essa função deve seguir o protótipo:
int ultimo(Lista* l);
Entrada
A primeira linha é composta por dois inteiros N, que representam respectivamente o número de elementos da lista.
A segunda linha é composta por N inteiros que representam os elementos presentes na lista.
Saída
Como saída imprima o retorno da função ultimo.

## Dicas

Não altere a main
